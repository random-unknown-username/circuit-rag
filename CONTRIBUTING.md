# Contributing

CIRCUIT is a local memory harness. Keep CLI commands thin, workflows reusable, and provider adapters independent. Source files and manifests are placeholders; no builds or tests work yet.

For product work, preserve provenance and test ingestion, retrieval, citations, and source lifecycle. For CIRCUIT-LCE research, follow the geometry gates and numerical contracts before performance optimization. Never commit private memories, credentials, corpus payloads, or generated checkpoints.

Record external inspiration and attribution in integrations/reference-projects.md. Read docs/third-party.md before importing source. Report real measurements with timing boundaries and state what remains unverified.
