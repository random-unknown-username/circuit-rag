# Learning from other projects

No external implementation has been imported.

For each inspiration, record the upstream URL, exact revision, license, idea adopted, and local destination in integrations/reference-projects.md. Distinguish an independently implemented idea from copied or modified source. Preserve required copyright and license notices alongside imported code.

Prefer small adapters or pinned dependencies over copying a whole harness. Keep domain contracts independent of upstream SDKs. Check compatibility before choosing the project license. Third-party code must not be presented as original CIRCUIT work.
