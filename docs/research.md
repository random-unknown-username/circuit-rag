# Retrieval research

CIRCUIT-LCE supports the memory product. Its question remains whether learned hierarchy geometry can make conservative support bounds selective enough on real held-out queries. See research/README.md for gates and docs/retrieval-engine.md for the execution boundary.

Experiments: oracle support ceiling → envelope gap → frozen-encoder hierarchy learning → optional geometry/representation adaptation → GPU execution → deferred storage scaling. Reconstruct certificates from actual corpus members after learning. Exactness, semantic retrieval quality, and answer quality are separate measurements.
